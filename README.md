# Machine Learning Klasifikasi Era Iron Man

## Deskripsi
Proyek ini menggunakan algoritma Decision Tree
Classifier untuk memprediksi era armor Iron Man
berdasarkan data yang dimasukkan.

## Dataset
Dataset berisi informasi armor Iron Man, seperti:
- Codename
- Primary Ability
- Date Made
- Era

## Algoritma
Decision Tree Classifier dengan preprocessing
menggunakan ColumnTransformer dan OneHotEncoder.

## Evaluasi Model
- Akurasi pengujian: 92.31%
- Model disimpan dalam file model_ironman.pkl.

## Cara Menjalankan
1. Jalankan python main.py untuk melatih dan
   mengevaluasi model.
2. Jalankan python uji_model.py untuk menggunakan
   model tersimpan dan melakukan prediksi interaktif.
