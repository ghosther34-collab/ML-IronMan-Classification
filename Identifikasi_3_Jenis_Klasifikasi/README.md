# Identifikasi 3 Jenis Klasifikasi Machine Learning

## 1. Deskripsi Project

Project ini dibuat untuk mengidentifikasi tiga jenis klasifikasi dalam Machine Learning, yaitu Binary Classification, Multiclass Classification, dan Multilabel Classification.

Proses identifikasi dilakukan menggunakan bahasa pemrograman Python dan library Pandas. Setiap dataset dianalisis berdasarkan jumlah data, jumlah fitur, jumlah kelas atau label, serta distribusi target.

## 2. Tujuan Project

Tujuan dari project ini adalah:

1. Memahami perbedaan Binary, Multiclass, dan Multilabel Classification.
2. Mengidentifikasi jenis klasifikasi berdasarkan dataset.
3. Menggunakan Python dan Pandas untuk membaca serta menganalisis data.
4. Menampilkan hasil analisis melalui program Python.

## 3. Dataset yang Digunakan

### A. Binary Classification — Banknote Authentication

**Sumber Dataset:**  
https://archive.ics.uci.edu/dataset/267/banknote+authentication

Dataset Banknote Authentication digunakan untuk mengidentifikasi keaslian uang kertas berdasarkan karakteristik statistik dari gambar uang kertas.

**Hasil Identifikasi:**
- Jumlah data: 1.372 baris
- Jumlah fitur: 4
- Jumlah target: 1 kolom (`class`)
- Jumlah kelas: 2
- Distribusi kelas:
  - Kelas 0: 762 data
